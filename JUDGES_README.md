# JUDGES_README — ROADSoS | SIH 2026

## Project Summary

ROADSoS is an AI-powered road crash emergency response system built specifically for India's national highway infrastructure. It detects crashes via G-force simulation, dispatches to the 108 GVK EMRI network, provides multilingual AI triage, and auto-files iRAD MoRTH reports — all within the Golden Hour. Built on React 19, Node.js, Socket.io, and Claude AI via OpenRouter.
