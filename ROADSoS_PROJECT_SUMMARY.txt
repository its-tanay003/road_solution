# ROADSoS – EMERGENCY INTELLIGENCE PLATFORM
# PROJECT SUMMARY & TECHNICAL MANIFESTO

## 1. PROJECT OVERVIEW
ROADSoS is a high-stakes, real-world ready Emergency Operating System designed to bridge the gap between accident occurrence and professional rescue. It transforms the "Golden Hour" of emergency response through AI-driven triage, cinematic visual intelligence, and resilient communication architectures.

## 2. CORE SYSTEM FEATURES
### A. Intelligent SOS Triggering
- **Multi-Modal Activation**: Support for manual hardware-simulated triggers and voice-activated SOS ("Emergency Help").
- **Autonomous Detection**: Simulated G-Force trigger (12.4G) with a 10s consciousness countdown for automatic rescue initiation.
- **Cinematic Experience**: High-stress visual overlays, heartbeat audio cues, and red-alert UI states.

### B. AI Triage & Decision Core
- **Claude-Powered Triage**: Real-time conversational AI that assesses victim status, injury severity, and vehicle dynamics.
- **Decision Transparency**: "AI Thinking" overlay that streams the system's logic (e.g., "Analyzing crash dynamics", "Selecting nearest ALS responder").
- **Multilingual Support (India Focus)**: Integrated i18next support for **English, Hindi (हिन्दी), and Tamil (தமிழ்)** to ensure localized accessibility.
- **Regional Compliance (India)**: Simulated integration with India's **112 emergency system** and **iRAD (Integrated Road Accident Database)** for MoRTH-aligned reporting.

### C. Real-Time Command & Control
- **Dynamic Dashboard**: High-density view featuring live telemetry, incident timelines, and map-based tracking.
- **Live Map Integration**: Dark-themed Leaflet maps with custom markers for Hospitals, Police, and Ambulances.
- **India Black Spot Heatmaps**: iRAD-based risk overlays highlighting high-incident zones across Indian National Highways.

### D. Resilience & Privacy
- **Mesh Mode Simulation**: P2P communication simulation for internet-deprived or rural environments.
- **ZK-Medical Encryption**: Client-side AES-GCM encryption for sensitive medical profiles, ensuring privacy during transmission.
- **Offline-First PWA**: Service Worker integration for sub-second UI responsiveness and map caching.

### E. Tactical Drone & AR Recon
- **Autonomous Drone Dispatch**: Simulated "Recon DR-1" drones with real-time video feeds for immediate scene assessment.
- **Responder AR HUD**: 3D spatial guidance (Three.js) for responders, featuring turn-by-turn navigation and impact physics simulation.
- **Vaahan Dynamic Context**: Real-time victim-vehicle telemetry (insurance, owner, RTO) for responders.

### F. Presentation & Demo Orchestration
- **Pitch Mode**: Integrated 5-slide immersive pitch deck for rapid hackathon storytelling.
- **Global Orchestrator**: Centralized demo controller with time dilation (0.5x, 1x, 2x) and internet-kill scenarios.
- **Hotkey Architecture**: Comprehensive keyboard-driven triggers for foolproof live demonstrations.

## 3. TECHNICAL ARCHITECTURE
### Frontend (The Nerve Center)
- **Framework**: React 19 + Vite 8.
- **Styling**: Tailwind CSS 4 + Framer Motion (for cinematic transitions).
- **3D Visualization**: Three.js for AR navigation and vehicle impact modeling.
- **State Management**: Zustand with persistent storage for demo telemetry and medical records.
- **Logic**: Custom hooks for Geolocation, Wake-word detection, and Network monitoring.

### Backend (The Intelligence Core)
- **Engine**: Node.js + Express.
- **Real-Time**: Socket.io for bi-directional emergency updates.
- **AI Integration**: Anthropic Claude API for sophisticated triage and response planning.
- **Observability**: Built-in Prometheus metrics endpoint for system health monitoring.

## 4. PRODUCTION HARDENING & DEPLOYMENT
