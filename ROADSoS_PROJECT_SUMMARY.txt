# ROADSoS – EMERGENCY INTELLIGENCE PLATFORM
# PROJECT SUMMARY & TECHNICAL MANIFESTO

## 1. PROJECT OVERVIEW
ROADSoS is a high-stakes, real-world ready Emergency Operating System designed to bridge the gap between accident occurrence and professional rescue. It transforms the "Golden Hour" of emergency response through AI-driven triage, cinematic visual intelligence, and resilient communication architectures.

## 2. CORE SYSTEM FEATURES

### A. Implemented Features (Live & Functional)
- **Next.js App Router Architecture**: Production-hardened full-stack framework with Server Components and API Routes.
- **Supabase Authentication & Database**: Real-world OAuth (Google/Apple) integration with secure session handling and UUID generation.
- **WebRTC P2P Mesh Fallback**: Functional peer-to-peer communication layer designed to sustain connections when primary network fails.
- **Offline-First PWA**: Service Worker caching enabled for sub-second UI responsiveness.
- **Cinematic Experience & UI**: High-stress visual overlays, heartbeat audio cues, and red-alert UI states fully implemented via Tailwind CSS 4 and Framer Motion.
- **Multilingual Support**: Real i18next support for English, Hindi, and Tamil.

### B. Simulated Features (For Hackathon/Demo Purposes)
- **Autonomous G-Force Detection**: Simulated 12.4G trigger with a 10s consciousness countdown (mocked hardware trigger).
- **108 GVK EMRI Dispatching**: Robust mock engine for dispatching, automating resource assignment, and real-time ETA countdowns.
- **Drone Recon Dispatch**: Simulated "Recon DR-1" drones with placeholder/simulated video feeds.
- **Responder AR HUD**: 3D spatial guidance (Three.js) is implemented visually but currently uses simulated routing data.
- **Pitch Mode & Hotkey Architecture**: Built-in 5-slide immersive pitch deck and demo-controller with time dilation scenarios.

### C. Planned Features (Future Roadmap)
- **MoRTH iRAD Integration**: Direct API connections to the Integrated Road Accident Database.
- **112 Emergency System Live Link**: Live bi-directional data flow with state emergency response centers.
- **ZK-Medical Encryption**: Future migration to Zero-Knowledge AES-GCM encryption for transmission of sensitive medical profiles.
- **Live Vaahan Telemetry**: Real-time victim-vehicle telemetry via RTO databases.

## 4. TECHNICAL ARCHITECTURE
### Frontend (The Nerve Center)
- **Framework**: Next.js 14 App Router + React 19.
- **Styling**: Tailwind CSS 4 + Framer Motion (for cinematic transitions).
- **3D Visualization**: Three.js for AR navigation and vehicle impact modeling.
- **State Management**: Zustand with persistent storage.

### Backend (The Intelligence Core)
- **Engine**: Next.js Serverless API Routes + NextAuth v5 + Supabase.
- **Dispatch Simulation**: Robust mock engine for **108 GVK EMRI** dispatching, featuring automated resource assignment and real-time ETA countdowns.
- **Notifications**: Integrated WhatsApp alert simulation and iRAD-compliant JSON report generation.

## 5. STABILITY & PRODUCTION HARDENING
- **Dependency-Lean Logic**: Replaced unstable third-party plugins (react-hot-toast, chartjs-annotation) with custom, lightweight Framer Motion and CSS solutions to ensure 100% demo uptime.
- **Type-Safe HMR**: Enforced `import type` for state machines to resolve Next.js Server Component bundling edge cases.
- **Accessibility Fixes**: Resolved critical missing hook and title attribute lints for a judge-ready presentation.
