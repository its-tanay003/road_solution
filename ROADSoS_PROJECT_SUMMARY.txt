# ROADSoS PROJECT SUMMARY

## Product Intent

ROADSoS is a road-emergency intelligence platform focused on crash/SOS activation, medical profile access, emergency contact notification, first-aid/AI triage, real-time map workflows, and control-room response views.

## Production Architecture

The active production source of truth is:

`C:/New Volume (D)/mandi/roadsos`

Primary stack:

- Next.js App Router
- React 19
- NextAuth v5
- Supabase database/auth/storage
- Vercel hosting
- Playwright E2E tests

Legacy code:

- `frontend/` is the old Vite app.
- `backend/` is the old Express backend.
- `archive/` contains historical demo material.

## Operational Notes

OAuth providers must be real provider credentials. Mock credentials, demo OTPs, and fallback secrets are not valid production authentication.

Admin access is controlled by `ADMIN_EMAILS`. Supabase RLS remains the final data boundary and must be tested with real user/admin sessions.
